# The Sundered Reach

A turn-based, story-driven browser RPG in the Spiderweb Software tradition. Four strangers each see one symptom of a dying world, and only together can they see the whole disease.

**Play:** https://jasonmcarpenter-netizen.github.io/sundered-reach/ (GitHub Pages, deployed from `main`), or open `index.html` through any static web server.

**Run locally:**
```
python3 -m http.server
# then open http://localhost:8000
```

**Built so far:** all of Act 1: three chapters each for Kael, Ilsa, Tamsin and Wren, ending with all four in Corvane. Act 2 is next.

**Saving across devices:** choose "Sign in to sync" on the title screen or in the menu and sign in with Google. Your progress then follows you to any device where you sign in. Signed out, the game saves on the device you're playing on. You can also move a save by hand: Menu → save code, then "Use a save code" on the title screen of the other device.

See `CLAUDE.md` for the design rules and code layout.
